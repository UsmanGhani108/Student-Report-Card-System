# Student Report Card System

A beginner-friendly Python project that generates a student's report card using basic Python programming concepts.

## Project Overview

The Student Report Card System takes a student's name and marks for five subjects, calculates the total marks and percentage, assigns a grade, and determines whether the student has passed or failed.

This project was created as a practical exercise to strengthen Python fundamentals.

## Features

* Takes student name as input
* Takes marks for five subjects
* Stores marks in a list
* Stores student information in a dictionary
* Calculates total marks using a `for` loop
* Calculates percentage
* Rounds the percentage
* Assigns a grade based on percentage
* Determines Pass/Fail status
* Displays the complete student record

## Subjects

The project currently includes:

* English
* Mathematics
* Urdu
* Chemistry
* Physics

## Grading System

| Percentage | Grade |
| ---------- | ----- |
| 90–100%    | A+    |
| 80–89%     | A     |
| 70–79%     | B     |
| 60–69%     | C     |
| 50–59%     | D     |
| Below 50%  | F     |
